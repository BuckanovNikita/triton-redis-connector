### 11.5.1 Add long-test example with Redis populate cycle

**Create:** `examples/long_test/`

This example demonstrates sustained Redis pipeline testing with continuous image population.

**Files:**
- `examples/long_test/__init__.py`
- `examples/long_test/run_long_test.py` — main script
- `examples/long_test/config.yaml` — config with model name, Redis stream, duration, rate

**`run_long_test.py` behavior:**
- Accept: `--duration-minutes`, `--images-per-second`, `--image-dir`, `--model-name`
- In a loop for the specified duration:
  - Read images from directory (cycle if fewer than needed)
  - Push to Redis input stream at specified rate using `time.sleep(1/rate)`
  - Log throughput every 10 seconds via tqdm
- At end: report total images pushed, average push rate
- Use `redis.Redis` directly (no connector dependency — this is a test utility)

### 11.5.4 Verify drift with low filter thresholds

When comparing inference results, use low confidence and IoU thresholds to capture ALL detections and ensure no drift is hidden by aggressive filtering.

**Why:** At high thresholds (conf=0.25, iou=0.45), many detections are filtered out before comparison, masking subtle drift. Low thresholds (conf=0.1, iou=0.1) expose the full detection set for comparison.

**Manual verification steps** (add to `docs/test_manuals/test_compare.md`):

1. Run inference with low thresholds:
   ```bash
   uv run triton-model-tools infer -m yolo11s --url localhost:8001 \
     -i e2e_results/coco_val2017 -o e2e_results/infer_low_thresh \
     --conf-threshold 0.1 --iou-threshold 0.1
   ```
2. Run ultralytics predict with same low thresholds:
   ```bash
   uv run triton-model-tools predict -m yolo11s \
     -i e2e_results/coco_val2017 -o e2e_results/predict_low_thresh \
     --conf-threshold 0.1 --iou-threshold 0.1
   ```
3. Compare:
   ```bash
   uv run triton-model-tools compare-folders e2e_results/infer_low_thresh e2e_results/predict_low_thresh
   ```
4. Repeat for all model variants (yolo11s, yolo12s, yolo26s, yolo26l) and their db/fp16/ort_trt variants
5. Drift at low thresholds should still be within tolerance (precision/recall > 0.95)

**Important:** All drift verification runs (steps 11.5.2-11.5.4) must use low thresholds. The default thresholds in CLI should remain 0.25/0.45 for normal usage, but verification scripts must explicitly pass `--conf-threshold 0.1 --iou-threshold 0.1`.
