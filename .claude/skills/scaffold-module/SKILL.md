# Scaffold Module

Create new workspace packages or submodules with all required configuration updates.

## Step 1: Determine Scope

Ask the user:
- **Package or submodule?** — new workspace package under `packages/` or new submodule within an existing package?
- **Name** — Python-valid snake_case name (e.g., `triton_shared_models`, `connectors`)
- **Parent package** — if submodule, which package does it belong to?
- **Dependencies** — any package dependencies beyond the workspace defaults?

## Step 2A: New Workspace Package

For a new package (e.g., `triton_shared_models`):

### 2A.1 Create package structure

```
packages/<name>/
├── pyproject.toml
├── <name>/
│   ├── __init__.py        # with from __future__ import annotations + docstring
│   └── py.typed           # empty PEP 561 marker
└── tests/
    └── test_placeholder.py
```

### 2A.2 Write pyproject.toml

Follow the pattern from `packages/triton_model_tools/pyproject.toml`:
- Build system: hatchling
- Python requirement: `>=3.12`
- Version: `0.1.0`
- User-specified dependencies

### 2A.3 Write __init__.py

```python
from __future__ import annotations

"""<Package description>."""
```

### 2A.4 Write test_placeholder.py

```python
from __future__ import annotations

def test_<package>_import() -> None:
    import <package_name>  # noqa: F401, PLC0415
```

### 2A.5 Update root pyproject.toml

Update these sections (read the file first to find current values):

1. **mypy_path** in `[tool.mypy]` — add `packages/<name>` to the comma-separated list
2. **testpaths** in `[tool.pytest.ini_options]` — add `packages/<name>/tests`
3. **paths** in `[tool.vulture]` — add `packages/<name>/<name>`
4. **source** in `[tool.coverage.run]` — add `<name>` to the list
5. **import-linter root_packages** in `[tool.importlinter]` — add `<name>` if it will have architecture contracts

### 2A.6 Update pyrightconfig.json

Add `packages/<name>` to the `include` array.

### 2A.7 Verify

```bash
uv lock
uv run ruff check .
uv run mypy .
uv run pyright
uv run pytest packages/<name>/tests/
```

## Step 2B: New Submodule

For a new submodule within an existing package (e.g., `connectors` in `triton_redis_connector`):

### 2B.1 Create submodule structure

```
packages/<parent>/<parent>/<submodule>/
├── __init__.py    # with from __future__ import annotations + docstring
```

### 2B.2 Verify import-linter contracts

Check if the new submodule fits within existing layer architecture contracts
in `pyproject.toml`. If it introduces a new layer, update the contracts.

### 2B.3 Verify

```bash
uv run ruff check .
uv run mypy .
uv run lint-imports
```

## Configuration File Reference

Files that need updating for new packages:
- `pyproject.toml` (root) — mypy_path, testpaths, vulture paths, coverage source, import-linter
- `pyrightconfig.json` — include array
- `uv.lock` — regenerated by `uv lock`

Files that need checking for submodules:
- `pyproject.toml` (root) — import-linter contracts (layer placement)
